# Computação Gráfica – 2026.1

Repositório da disciplina **Computação Gráfica** da UFAL, **2026.1**.
Contém exercícios e exemplos desenvolvidos durante a disciplina utilizando **C, OpenGL e GLUT**.

## Tópicos abordados

* Rasterização
* Transformações geométricas 2D e 3D
* Modelagem geométrica
* Projeção
* Processo de visualização 2D e 3D
* Modelos de iluminação
* Texturização

## Objetivo

Estudar técnicas e algoritmos utilizados para gerar, manipular e visualizar imagens, aplicando conceitos de modelagem, transformação e renderização.
